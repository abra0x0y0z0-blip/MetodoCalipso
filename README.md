# El Método Calipso

**Una Propuesta para un Aprendizaje Vivo**  
*Forjando Exploradores Resilientes — De la Curiosidad a la Mentalidad de Crecimiento*

## 📖 Sobre este proyecto

El Método Calipso es una propuesta educativa basada en neurociencia, pedagogía del juego y andragogía, diseñada para acompañar el aprendizaje desde la infancia hasta la vida adulta.  

No es una crítica al sistema educativo, sino una invitación a complementarlo con curiosidad, exploración y mentalidad de crecimiento.
